# Houses_prices_in_California
End-to-end machine learning project that predicts California housing prices using a regression pipeline and is deployed as an interactive web app.


## Synent Technologies Internship Project

synent-task<task 1>-<Houses_prices_in_California>-<Believe Nosakhare>
```

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Files
```bash
app.py
model.pkl
README.md
requirements.txt
```

## Run the App

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the Streamlit app:

```bash
streamlit run app.py
```

## Input Features
- Longitude
- Latitude
- Housing Median Age
- Total Rooms
- Total Bedrooms
- Population
- Households
- Median Income
- Ocean Proximity

## Output
The app predicts the estimated California house price based on the entered data.
